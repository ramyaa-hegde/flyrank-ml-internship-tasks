00 / ABSTRACT

The study, in brief.

Can February signals identify content items likely to fall below their position-adjusted CTR benchmark in March?

This project compares a transparent February-only ranking rule with a Random Forest classifier on whole pseudonymized clients held out from training. The learned model improved Precision@20 from 0.25 to 0.90, helping a content or SEO team focus a small manual-review queue. The result is observational decision support—not proof that an edit will cause more clicks.

Research boundary

The system ranks review opportunities. It never changes titles, snippets, URLs, content, or publishing status.

01 / PROBLEM FRAMING

03 / BASELINE

A simple rule earns the right to be beaten.

Rank eligible February positions 4–20 by February impression volume; all other items receive a score of zero.

eligible visibility+February demand→review rank

The baseline is intentionally transparent, available before the March outcome, and evaluated on the same held-out clients as the model.

04 / MODEL & ANALYSIS

Built for non-linear search behavior.

Random Forest classifier

Numeric features use median imputation with missingness indicators. Categorical features use most-frequent imputation and one-hot encoding. Entire clients stay in either training or validation, producing 21 training clients and 12 unseen validation clients with zero overlap.

05 / EVALUATION

The learned ranking finds more relevant review candidates.

On held-out pseudonymized clients, the model leads the February-only baseline on every reported ranking metric.

Why Precision@20?

It measures how many genuine March proxy-positive items appear in a deliberately small queue that a content team can realistically review.
